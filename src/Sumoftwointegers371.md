# 문제 풀이
두 정수의 합을 구하라 + 또는 - 연산자는 사용할 수 없다

전가산기는! 반가산기 2개를 합친것이다.
반가산기는 
sum= x^y이고
carry= x&y이다

그럼 전가산기는
첫번째 반가산기의 결과인 sum과 z를 토대로 계산을 하되
캐리를 구할때 그전에 구한 캐리와 논리합하는 계산을 추가로 실행한다

sum2=sum^z
carry2= sum&z +carry
이젠 이거를 알고리즘으로 구현을 하면 된다!

1. 정수의 입력을 받아 저장한다
2. 2~4번을 32번 반복한다
3. 1차 sum과 캐리를 구한다
   - s1=x^y
   - carry=x&y
4. 2차 sum과 캐리를 구한다
    - s2=s1^z
    - carry=s1&z|carry
5. 2차 sum를 list에 add한다
6. list를 문자열으로 변환하여 리턴한다
