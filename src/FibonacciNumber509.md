- # 문제풀이
  - 피보나치수란?: 앞 두숫자의 합이 값인 수이다
  - 재귀적으로 푸는 코드는 이미 알고 있다
  -     public int fib(int n) {
        if (n==0){
            return 0;
        }
        if (n == 1) {
            return 1;
        }
        return fib(n-1)+fib(n-2);
    }
  - 그런데 큰수부터 0과 1까지 도달하고 나서 리턴값을 더하는 방식보다는
  - 처음부터 0과 1를 더해 주어진 수까지만 더하는게 더 효율적이다.

    - n을 받는다
    - n-2인 z, n-1인 y를 더한값을 x에 저장한다
    - z에 y값을 저장한다
    - y에 x값을 저장한다
    - 턴이 끝난후 x를 반환한다
    - 이런 알고리즘이면 될것같다.
